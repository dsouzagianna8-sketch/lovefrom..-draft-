# Love From… prototype

Clickable prototype for **Love From…**: plan the letters, memories and gifts your people receive after you're gone. Like a will, but for your terrible jokes.

Live demo: https://dsouzagianna8-sketch.github.io/lovefrom..-draft-/

- **Sender journey:** pick a person → write a letter, record a memory or choose a gift → choose when → seal it
- **My keepsakes:** a little collection per person, re-time or remove anything
- **Receiver journey:** "Sam left you a message" → open, keep for later or decline

Use the demo bar (bottom left) to jump between the sender and receiver sides. All content is example data and resets on reload.

Student project, Break the Rules brief.
